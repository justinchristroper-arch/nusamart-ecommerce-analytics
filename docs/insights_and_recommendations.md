# Key Insights & Recommendations — NusaMart

> **Aturan penulisan**
> - *Finding* dan *Evidence* hanya berisi fakta dari hasil query/dashboard, lengkap dengan angka dan sumber query.
> - *Possible explanation* selalu ditandai sebagai **hipotesis**.
> - *Expected impact* ditulis sebagai arah dampak, bukan angka karangan.
> - Target: 5–7 insight. Kualitas lebih penting dari jumlah.

---

## Template (salin untuk setiap insight)

### Insight N — [judul singkat, berupa kesimpulan]

**Finding:** apa yang terjadi, 1–2 kalimat.

**Evidence:** angka pendukung + sumber (contoh: `sql/03_customer_analysis.sql` Q4a; halaman Customer Analysis).

**Possible explanation (hipotesis):** kemungkinan penyebab, dan data apa yang dibutuhkan untuk membuktikannya.

**Recommendation:** tindakan konkret, siapa pemiliknya (stakeholder), dan cara mengukur keberhasilannya.

**Expected impact:** arah dampak yang diharapkan + risikonya.

## Keterbatasan analisis
- Tidak ada data cost/profit; beban ongkir dipakai sebagai proxy.
- Tidak ada data promo, channel marketing, atau kompetitor, sehingga penyebab tidak dapat dibuktikan.
- Data historis (bukan real-time); hasil mencerminkan periode dataset.
